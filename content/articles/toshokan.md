「枚方の図書館って、なんであんなに立派なん？」「枚方は図書館がすごいって聞くけど、ほんま？」と聞かれたときに、説明できるページです。


## まとめ

- <mark>**車塚の中央図書館は、関西外国語大学の図書館だった建物**</mark>。1994年に大学の図書館として完成し、枚方市が寄付を受けて改修、2005年4月17日に開館しました
- それまでの中心の図書館は、枚方市駅に近い市民会館の3階にありました。狭く、エレベーターもありませんでした
- <mark>**枚方の市立図書館は 1973年、子ども連れのお母さんたちの陳情から始まった**</mark>。それまでは、蔵書7,119冊の「図書センター」だけでした
- <mark>**貸出冊数は、2024年度まで4年連続で中核市1位**</mark>。2025年度は 441万3171冊でした
- <mark>**住民1人あたりの貸出は、2024年度に大阪府内43市町村で3位（10.5冊）。全国平均（2023年度 4.8冊）の2倍あまり**</mark>。上には箕面市と茨木市がいます
- 本の数（蔵書）は府内5位、1人あたりでは25位と多くありません。<mark>**少ない本をよく回していて、蔵書回転率は府内1位**</mark>（どれも2024年度）
- いまは中央図書館と分館8つ、分室6つ、移動図書館（自動車文庫）があります。2024年には枚方市駅前のステーションヒル枚方に市駅前図書館ができました

## 中央図書館は、関西外大の図書館だった

<mark>車塚2丁目にある枚方市立中央図書館は、もとは関西外国語大学の図書館です。</mark>関西外大の片鉾キャンパス（片鉾学舎）に、新しい図書館の建物として 1994年に完成しました[^gaidai]。その後、大学はキャンパスを移すことになり、跡地は枚方市が防災の拠点などとして整えることになります[^40nen-chuo]。

<div data-photo="Hirakatashiritu-chuo-toshokann-for-wiki.jpg"></div>

2001年8月、関西外大から図書館の建物を寄付したいという申し出があり、2002年3月に寄付されました[^nenpyo]。<mark>完成から8年ほどの大学図書館を、市はそのまま図書館として使うことにしたのです。</mark>2004年に耐震とバリアフリーの改修工事をして（建築工事の契約は3億6,330万円）[^kansa]、<mark>2005年4月17日に中央図書館として開館しました</mark>[^nenpyo][^nenpo2025]。

| | |
|---|---|
| 所在地 | 枚方市車塚2丁目1-1[^nenpo2025] |
| 建物 | 地下1階・地上7階建て、図書館の面積 9,301.77㎡[^nenpo2025] |
| 開館 | 2005年4月17日[^nenpyo] |
| 開館のときの本 | 開架11万5千冊、しまえる本は50万冊[^nenpyo] |
| 2025年度の蔵書 | 42万9,360冊（全館では 123万3,857冊）[^nenpo2025] |

最寄りは京阪バスの「片鉾・中央図書館前」です。京阪の駅からは遠く、牧野駅から歩くと20分ほどかかります[^guide]。

### その前は、市民会館の3階だった

中央図書館ができる前、中心の図書館（枚方図書館）は、枚方市駅近くの市民会館の3階にありました[^nenpo2024]。市の『枚方市立図書館四十年誌』は、<mark>「枚方市駅に近いなどの利点はあったが、閲覧スペースが狭い、蔵書数が少ない、3階にあるのにエレベーターがない」</mark>と書いています[^40nen-chuo]。

<div data-photo="Hirakata_Civic_Hall_-_panoramio.jpg"></div>

中央図書館をつくる構想は 1980年からありましたが、約20年、具体的には進みませんでした。2001年度の市政モニターの調査では、8割が「中央館が必要」と答えています[^40nen-chuo]。そこへ関西外大の寄付の話が来て、一気に実現したわけです。

枚方図書館は 2004年11月に休館して本を中央図書館に移し、2005年3月に閉館しました[^nenpyo]。

## 始まりは、子ども連れのお母さんたちの陳情

<mark>1972年の枚方市にあった図書館らしいものは、市民会館3階の「図書センター」だけでした。</mark>蔵書7,119冊、1年の貸出 9万7,228冊、広さ 440㎡。人口25万人を超えた市なのに、当時の市職員は「図書館ではない」と書いています[^ishibashi]。

1972年7月、家庭や地域で子どもに本を貸していた「文庫」の人たちが集まって、「子どもの本をひろめる会」をつくります[^nenpo2024]。リーダーは小学校の先生の橋詰淳子さんでした[^ishibashi]。<mark>市長応接室での陳情には、入りきれないほど、100人を超える子ども連れのお母さんたちが集まりました。</mark>これを見た山村富造市長が、図書館に力を入れると約束したといいます[^ishibashi]。

市役所の中から図書館づくりを後押ししたのが、1972年に市役所に入り、のちに教育長になる家高憲三さんです[^ishibashi]。<mark>家高さんは市長に「市長、こら票になりまっせ」と言ったそうです</mark>[^ishibashi]。

- 1972年11月：高知市、町田市、調布市から市長や図書館長を招いて「図書館行政を進める協議会」[^nenpo2024]
- 1973年3月：「枚方市立図書館条例」ができる[^nenpo2024]
- <mark>1973年4月：枚方市立図書館が開館</mark>[^nenpo2024]
- 1973年7月：移動図書館（自動車文庫）「ひなぎく号」が30か所を回り始める。香里・禁野・中宮・野田・津田に分室[^nenpo2024]

<mark>図書館の計画は「だいたい半径1500メートルにひとつ」</mark>。円からはみ出たところには分室をつくる、という考え方でした[^ishibashi]。家高さんは開発の決まり（開発指導要綱）に「千戸を超える大団地を建てるときは、団地の中に図書館の分室を建てて市に寄付する」と入れてもらい、藤阪分室（1975年）と釈尊寺分室（1979年）ができています[^ishibashi]。

その後、1979年の香里ケ丘図書館から、楠葉（1982年）、菅原（1983年）、山田（1985年）、蹉跎（1986年）、御殿山（1987年）、牧野（1988年）、津田（1990年）と、分館が次々にできました[^nenpo2024]。

## いまの枚方の図書館

いまは、中央図書館と分館8つ、分室6つ、移動図書館2台（ひなぎく号とカワセミ号）です。移動図書館は市内27か所を回っています[^nenpo2025]。

<div data-photo="Hirakata_municipal_Korigaoka_library.jpg"></div>

| | 場所 |
|---|---|
| 中央図書館 | 車塚 |
| 分館（8） | 香里ケ丘、楠葉、菅原、蹉跎（さだ）、御殿山、牧野、津田、市駅前 |
| 分室（6） | 村野、枚方公園、藤阪、宮之阪、香里園、氷室 |

<mark>2024年9月17日には、枚方市駅前のステーションヒル枚方の5階に「市駅前図書館」が開館しました</mark>[^nenpo2025]。

分館8つは、市が選んだ会社などが運営する「指定管理者制度」です。中央図書館と分室は、市の職員が運営しています[^nenpo2025]。

## どれくらい借りられている？

<div data-chart="library-lending"></div>

<mark>2025年度の貸出は 441万3171冊。これまでいちばん多かった 2009年度の 441万9687冊に、ほぼ並びました。</mark>市の年報は、<mark>貸出冊数が「令和６年度（2024 年度）まで４年連続中核市１位」</mark>だと書いています[^nenpo2025]。1989年度の約197万冊から見ると、2倍を超えています[^40nen-lending]。

2020年度は新型コロナで、予約した本の貸出だけにした時期があり、約266万冊に減りました[^nenpo2025]。

1972年の図書センターの貸出は1年で 9万7,228冊でした[^ishibashi]。それがいまは、その45倍です。

### 大阪府内で比べると

<div data-chart="library-per-capita"></div>

住民1人あたりの貸出冊数を、大阪府内の43市町村で比べました（2024年度の貸出を、2025年1月1日の人口で割った数）[^osaka-nenkan][^soumu]。

<mark>2024年度の枚方市は 10.5冊で、府内3位です。</mark>1位は箕面市（12.2冊）、2位は茨木市（12.0冊）。府内でいちばん人口の多い10市の中では、茨木市に次いで2番目です。大阪府全体は 5.4冊、大阪市は 3.4冊でした。

全国の平均は、2023年度で 4.8冊です[^mext]。同じ2023年度の枚方市は 9.9冊なので[^nenpo2025]、<mark>枚方の人は全国平均の2倍あまり、図書館で本を借りています。</mark>

### ランキングで見ると

同じ大阪府の統計（2024年度）で、ほかの数字も比べました。府内のほかの市町村とそろえて比べられる数字は、2024年度のものが最新です（2026年11月時点）。<mark>貸出は多いのに、本の数は多くありません。少ない本を、よく回しているのが枚方です。</mark>

| 大阪府内43市町村での枚方市（2024年度） | 数 | 順位 |
|---|---|---|
| 貸出冊数 | 410万3,346冊 | 2位（1位は大阪市） |
| 住民1人あたりの貸出冊数 | 10.5冊 | 3位 |
| 蔵書回転率（貸出 ÷ 蔵書） | 3.31回 | 1位 |
| 蔵書冊数 | 124万119冊 | 5位 |
| 住民1人あたりの蔵書冊数 | 3.2冊 | 25位 |
| 統計に載っている館の数 | 9館 | 4位（豊中市・吹田市と同じ） |

出典：大阪府統計年鑑 表18-1 と、総務省の人口から計算[^osaka-nenkan][^soumu]。

<mark>2024年度の貸出冊数は、人口が倍の堺市（383万6,330冊）より多く、府内では大阪市に次ぐ2位です。</mark>一方、1人あたりの本の数は 25位で、府内では少ないほうです。

<div data-chart="library-turnover"></div>

「蔵書回転率」は、1年に貸し出した本の数を、持っている本の数で割ったものです。<mark>2024年度の枚方は 3.31回で府内1位。持っている本1冊が、1年に3回あまり借りられている計算です。</mark>

館の数は、府の統計に載っている図書館（分館を含む）の数です。枚方の分室6つは載っていません。ほかの市には、公民館の図書室が載っているところもあります[^osaka-nenkan]。分室まで入れると、枚方は 15か所と移動図書館です[^nenpo2025]。
